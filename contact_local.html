About
WebSafe

Developed by students from STI College Fairview, WebSafe is a website URL malware detector designed to identify and neutralize malicious links. Built to protect Filipino internet users, the system integrates five industry-grade APIs — VirusTotal, WHOIS API, CheckPhish API, Google Safe Browsing, and URLSCAN.IO — to evaluate URLs in real time and ensure user safety.

Rather than relying on simple blocklists, WebSafe cross-references domain registration data, deep-learning phishing intelligence, VirusTotal's 70+ antivirus engines, Google's own malicious URL database, and live sandbox scans — all evaluated concurrently through Node.js's asynchronous architecture for sub-second results.

Inspired by the rising number of phishing scams targeting local communities, our team set out to make professional-grade URL verification free and accessible to everyone — no login required, no friction, just fast and reliable safety verdicts.

How WebSafe Is Built

Five industry-grade APIs work together in a multi-layer analysis pipeline — from domain registration data to live phishing intelligence, multi-engine antivirus scans, and deep sandbox inspection.

01

VirusTotal

Submits URLs to VirusTotal's aggregated engine, which checks against 70+ antivirus vendors and URL scanners simultaneously. The consensus result — how many engines flagged the URL — feeds directly into the final safety score.

02

WHOIS API

Retrieves domain registration data including creation date, registrar, and ownership status. Newly registered or anonymized domains are automatically weighted as higher risk, helping catch freshly spun-up phishing infrastructure.

03

CheckPhish API

Provides real-time phishing URL detection powered by deep learning models. CheckPhish scans every URL for phishing indicators, brand impersonation, and social engineering patterns that evade traditional blocklists.

04

Google Safe Browsing

Cross-references every URL against Google's continuously updated threat lists — covering malware, phishing, unwanted software, and social engineering pages. Flags are returned in real time as part of the safety score calculation.

05

URLSCAN.IO

Performs a deep sandbox scan of the target URL — loading the page in an isolated environment and capturing DOM structure, HTTP transactions, outgoing links, and behavioural signals. Results surface hidden redirects and malicious scripts invisible to simple checkers.

What WebSafe Evaluates on Every URL

Each URL is passed through all five integrated APIs concurrently. Results are normalised and weighted — a VirusTotal hit or a Google Safe Browsing flag carries heavier penalties than a domain age warning — and combined into a single safety score from 0 to 100.

The engine weighs each signal differently to ensure the final score accurately reflects the actual threat level rather than treating all checks as equal.

HTTPS & SSL Validation
Verifies end-to-end encryption and certificate validity. Sites without HTTPS lose 30 points immediately — a major red flag for data security.
Google Safe Browsing Lookup
Checks the URL against Google's threat lists covering malware, phishing, and unwanted software — updated in near real-time by Google's crawlers.
VirusTotal Multi-Engine Scan
Submits the URL to 70+ antivirus and URL scanner engines simultaneously. Even a single engine flag triggers a score penalty and an elevated warning.
CheckPhish Deep-Learning Scan
AI-powered detection of phishing pages, brand impersonation, and social engineering — catching threats that pattern-based blocklists miss entirely.
WHOIS Domain Age & Registrar
Queries registration records to flag newly created or anonymized domains — common tactics used by phishing campaigns to evade detection before blocklists catch up.

Standout Feature

Five APIs. One Verdict.

WebSafe's strength lies in layering five independent threat-intelligence sources into a single, weighted safety score. No single API has full coverage — together they form a near-complete picture of every URL's risk profile.

The result is displayed alongside a clear verdict — Safe, Suspicious, or Dangerous — with a breakdown of exactly which checks flagged the URL, giving users full transparency before they decide to click.

Multi-Engine Consensus
VirusTotal queries 70+ AV engines at once — a single flag triggers a warning even if the rest pass.
AI Phishing Detection
CheckPhish's deep-learning models catch brand impersonation and social engineering invisible to pattern-based filters.
QR Code Content Extraction
Decode QR-encoded URLs via camera or image upload — checked through all five APIs before opening.

Built With Purpose

Developed at STI College Fairview

WebSafe was created by students from STI College Fairview as a practical cybersecurity tool for Filipino internet users. Inspired by the rising number of phishing scams targeting local communities, the team integrated VirusTotal, WHOIS API, CheckPhish API, Google Safe Browsing, and URLSCAN.IO into a free, accessible, no-login-required tool — making professional-grade URL verification simple for everyone.
